# Concept Learner 概念学习资料生成器

## 适用场景

- 用户提出"帮我学习/搞懂/理解一下 XXX 概念"。
- 用户要求为某概念生成"学习笔记 / 学习资料 / 概念卡片"。
- 本仓库内需要为新概念补充学习资料（如老师布置了新的学习主题）。

本 Skill 的核心目标：把一个陌生概念转化为**结构完整、来源可核查、语言个人化**的学习资料，让学习者能读懂、能复述、能自测。它面向真实学习者，产出的是"人能看懂的笔记"，纯 AI 腔的百科式堆砌属于失败输出。

## 输入信息

执行前确认以下信息（缺省时给出合理默认并说明）：

| 输入项 | 说明 | 示例 |
|---|---|---|
| 概念名称 | 必填，要学习的概念 | `Agent` |
| 概念的英文/别名 | 可选，便于检索来源 | `AI Agent, LLM Agent` |
| 领域上下文 | 可选，帮助定位（默认 AI/大模型方向） | 人工智能 |
| 输出文件 slug | 可选，默认取概念名称的连字符形式 | `agent` |
| 输出目录 | 可选，默认 `learning-materials/` | `learning-materials/` |

## 生成步骤

按顺序执行，**每步都不可跳过**：

1. **澄清与命名**：确认概念名称；若有歧义（如同一词在不同领域含义不同），先和用户确认指的是哪个方向。
2. **来源规划**：先想清楚"这个概念的权威资料可能在哪"，优先级：官方文档/论文 > 权威机构技术博客 > 知名教材/维基 > 高质量二手解读。禁止凭空编造来源。
3. **检索与核对**：用网络搜索/查阅官方文档，**逐一核实**要引用的每条链接真实存在且内容相关。无法核实的内容不得写入。
4. **按模板写作**：按下方"输出结构"逐节撰写。语言要求：像一名认真自学的人用自己的话整理，允许保留口语化的理解性表述；禁止整段照搬搜索结果或 AI 生成文本；禁止堆砌术语却不解释。
5. **个人化加工**：为每个概念补一个"我自己的类比或理解"，说明这个概念跟自己已知的哪个东西像。这是本 Skill 的特色要求。
6. **自检**：对照下方"自检清单"逐条检查，不通过则回头修改。
7. **落盘**：将结果写入 `<输出目录>/<slug>.md`；如输出目录不存在则创建。完成后告知用户文件路径，并建议用户亲自通读核查一遍。

## 输出结构

生成的文件须包含以下部分（Markdown 一级/二级标题）：

1. **学习目标**：学完本概念，读者能回答哪 2-3 个问题。
2. **一句话理解**：≤ 3 句话的个人化解释，禁止照抄定义。
3. **核心机制 / 组成**：这个概念由什么构成、怎么运作。配一个简单的 Mermaid 图或列表说明过程。
4. **具体应用场景**：1-2 个真实、具体的例子（说明场景、输入、输出、为什么用它）。
5. **容易混淆的概念辨析**：列出 2-3 个易混概念，用表格对比。
6. **使用边界 / 常见误区**：什么情况下不该用它、容易犯的错误。
7. **自测问题**：3-5 道题（简答/判断/小场景题），附答案要点（用 `<details>` 折叠，便于自测）。
8. **参考来源**：真实链接列表，每条注明"是什么资料、为什么可核查"。

文件头部加 YAML 注释块或表格记录元信息：学习概念、生成日期、调用 Skill 名称、核查状态（默认标记"待人工核查"）。

## 资料来源要求

- **可核查优先**：官方文档、学术论文、标准原文 > 二手解读。本仓库作业明确规定"资料来源不得伪造"，引用前必须用搜索工具确认链接有效。
- **标注用途**：每个来源写明它支撑了文中哪个论断。
- **引用数量**：每份资料至少 3 个独立可核查来源。
- 不确定的、找不到出处的说法，宁可删掉或在文中明确标注"待考证"，严禁编造。

## 自检清单（落盘前逐条过）

- [ ] YAML 元数据在文件头部，概念名、日期、调用 Skill 已记录
- [ ] 八个输出小节全部存在、顺序符合模板
- [ ] "一句话理解"是自己的话，没有整段照搬
- [ ] 核心机制部分能讲清"它内部是怎么工作的"，而非只讲定义
- [ ] 有至少 1 个真实具体应用场景，且场景中概念用法正确
- [ ] 概念辨析表区分了 2 个以上易混概念
- [ ] 每条参考来源都经过核实，链接格式完整、可点击
- [ ] 全文语言通顺、个人化，没有明显 AI 腔（如"首先…其次…最后…"连发、空泛排比）
- [ ] 无敏感信息（密钥、隐私）混入
- [ ] 已在回复中建议用户亲自核查一遍内容

## 输出示例（节选）

```markdown
---
concept: Agent
generated_by: concept-learner
date: 2026-09-07
review_status: 待人工核查
---

# Agent 学习笔记

## 学习目标
1. 能用一句话向同学解释 Agent 和普通聊天机器人的差别
2. ...
```

## 注意事项

- 本 Skill 是"方法论包"，它本身不存储任何概念的知识——知识靠执行时检索获得。
- 对 AI 领域概念的写作要贴近当下生态（工具、模型迭代很快），尽量引用近两年的资料。
- 若用户要求学习的概念属于敏感/危险领域，礼貌说明无法协助生成学习资料。
